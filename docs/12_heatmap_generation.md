# 12. Heatmap Generation

## Overview
Heatmaps provide a visual representation of visitor engagement density within the store. They are generated by accumulating visitor track positions over a duration and overlaying them as a color-coded density map on the original store floor plan.

## Technical Implementation
- **Source**: `data/pipeline/heatmaps/run_heatmap.py`
- **Data Source**: Tracking JSON artifacts (`*_tracks.json`).
- **Processing**:
    1.  **Coordinate Aggregation**: Collect all `(center_x, center_y)` points from all tracks.
    2.  **Kernel Density Estimation (KDE)**: Create a 2D histogram of positions.
    3.  **Gaussian Smoothing**: Apply a blur kernel to create smooth intensity gradients.
    4.  **Color Mapping**: Map intensity values to a color gradient (Blue for low, Red for high activity).
    5.  **Overlay**: Blending the generated intensity map with the background frame using transparency (alpha-blending).

## Configuration
- `SCALE_FACTOR`: Downscales the image for faster processing without losing density trends.
- `GAUSSIAN_SIGMA`: Controls the "radius" of each visitor's influence on the map.
- `ALPHA`: Controls the transparency of the color overlay on the background image.

## Business Utility
- **Hotspot Identification**: Identifying high-engagement products or displays.
- **Dead Zones**: Identifying areas of the store that visitors rarely visit.
- **Path Optimization**: Visualizing common walking patterns to optimize shelf placement.
